Extending [Door's Locked, Try the Window](https://www.lesswrong.com/posts/GHrqBKr8GLpbce6mN/door-s-locked-try-the-window), a project which tested how often models circumvent permission blocks in order to complete a task. We'll be using the same evaluation structure while testing on Olmo 3 32B Think in different stages of RLVR training, and potentially expanding the number of tasks and the different ways a model could bypass permission blocks.
